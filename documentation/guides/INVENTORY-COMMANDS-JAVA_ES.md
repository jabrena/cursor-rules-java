# Inventario de Commands Integrados

## Objetivo

Proporcionar una lista de comprobación rápida de los commands integrados disponibles para su instalación en este repositorio.

## Commands integrados

| Command | Fase del SDLC | Propósito principal |
| --- | --- | --- |
| `/update-issue` | Análisis / Diseño | Actualizar issues existentes de GitHub o Jira con una user story estructurada, criterios de aceptación y contenido de recursos. |
| `/explore-problem` | Análisis / Diseño | Evaluar un issue desde cinco puntos de vista y publicar un comentario de especificación funcional en el issue. |
| `/create-acceptance-criteria` | Análisis / Diseño | Derivar criterios de aceptación en Gherkin a partir de un comentario de especificación funcional y publicarlos como un comentario separado en el issue. |
| `/create-feature-branch` | Análisis / Diseño a Implementación | Crear y cambiar a una rama con un nombre convencional para análisis, diseño o implementación respaldados por el repositorio. |
| `/create-worktree` | Análisis / Diseño a Implementación | Crear una rama aislada y un worktree vinculado para trabajo en paralelo. |
| `/create-adr` | Diseño | Registrar una decisión arquitectónica, sus alternativas, justificación y consecuencias. |
| `/create-diagram` | Diseño | Crear un diagrama de arquitectura o diseño centrado en artefactos aprobados. |
| `/create-spec` | Análisis / Diseño | Crear o actualizar uno o más cambios de OpenSpec validados. |
| `/explore-design` | Diseño | Comparar enfoques técnicos y obtener una dirección de diseño aprobada. |
| `/implement-spec` | Implementación | Entregar un plan aprobado o una lista de tareas de OpenSpec validada mediante delegación adaptada al framework. |
| `/profile` | Operación | Coordinar el profiling de Java desde la detección de la línea base hasta la optimización verificada. |
| `/benchmark` | Operación | Seleccionar y coordinar workflows de rendimiento con JMeter, Gatling o JMH. |
| `/close-spec` | Operación / Mantenimiento | Archivar un cambio de OpenSpec por nombre mediante la CLI de OpenSpec. |

## Opciones de destino de instalación

- `.github/commands`
- `.claude/commands`
- `.cursor/command`
- `.codex/commands`
