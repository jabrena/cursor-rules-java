## Summary

Spring PetClinic is Spring's reference sample application: a Spring Boot 4 web app (Maven build, `groupId org.springframework.samples`, `artifactId spring-petclinic`, parent `spring-boot-starter-parent:4.1.0`) built with Java 17+. The main package `org.springframework.samples.petclinic` holds `PetClinicApplication` (the `@SpringBootApplication` entry point) and `PetClinicRuntimeHints`, alongside four sub-packages: `owner` (Owner, Pet, Visit, PetType, and their controllers/repositories/validator/formatter — the core clinic domain), `vet` (Vet, Specialty, VetController, VetRepository, Vets — the veterinarian domain), `system`, and `model` (shared base types). The README documents running the app locally via `./mvnw spring-boot:run` or `./gradlew bootRun`, and building a container image with the Spring Boot build plugin (no Dockerfile is present in the repository).
